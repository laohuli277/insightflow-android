# 灵感流 · 独立安卓版

用更顺手的方式留下、整理和回顾灵感。

在 [Releases](https://github.com/laohuli277/insightflow-android/releases/latest) 下载最新签名 APK。已安装的新版 App 中，可在“更多 → 反馈与更新”检查、下载并安装更新。

反馈者无需 GitHub 账号。在 App 内填写反馈并确认公开范围后，反馈会先保存到云端队列，再自动归档到本仓库的 [Issues](https://github.com/laohuli277/insightflow-android/issues)。GitHub 定时工作流可能延迟；“云端已接收”与“已归档 GitHub”在 App 中分别显示。

请仅提交愿意公开的文字，不包含私人笔记、照片、账号密钥或联系方式。App 不会自动附加这些内容。

维护者在 Actions → Archive app feedback 可手动运行归档。GitHub 可能在长时间无仓库活动后停用定时工作流，需要维护者重新开启。更新发布不依赖反馈归档任务。

本仓库公开安装包、公开版本说明与自动化脚本，不包含私人笔记、AI/OSS 凭据或应用签名私钥。正式发布的 APK 沿用相同签名以保留原安装数据；卸载或清除数据会删除本机内容，请先导出加密备份。
